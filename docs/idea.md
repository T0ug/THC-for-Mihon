# Idea

## Project

Toug - The Hentai Comics

## Intent

Create a Mihon extension for the adult content source `thehentaicomics.com`.

The extension should let Mihon users browse and read content discovered through the site's XML sitemaps, starting from:

`https://thehentaicomics.com/sitemap_index.xml`

## Initial Goal

Build an MVP extension that exposes the source inside Mihon with an initial `Latest` listing based on sitemap entries.

## Audience

Users of Mihon who want to access this specific source through Mihon.

## Content Context

The source contains adult content. The extension will expose the site's content as provided by the source in the MVP.

## Distribution Intent

The project should be prepared from the beginning for possible future distribution in an extensions repository.
