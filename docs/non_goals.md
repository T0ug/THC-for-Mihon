# Non-Goals

The project will not include:

- Tag filters.
- Category filters.
- A separate app screen or standalone APK experience beyond being a Mihon extension.
- Grouping multiple URLs into shared series or chapter structures.
- A custom local cache or persistent sitemap index.
- Full-site pre-indexing before showing initial results.

## Items removed from non-goals (scope expanded)

- Title search — removed on 2026-05-09, user requested implementation (see decision_log.md).
- A populated `Popular` listing — removed on 2026-05-09, implemented via TASK-009.
